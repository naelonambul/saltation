# Refresh optimizer statistics for restored outbox captures

## Evidence and scope

A Mac mini crossover on copies of the same verified three-year dump reproduced the ordinary outbox regression in both controls. Gathering only OUTBOX table and index statistics after fixture load and invalidating its dependent cursors moved the executing SQL to OUTBOX_PK with WINDOW NOSORT STOPKEY. Both treatment runs reduced Oracle work and exceeded the prior Step 2 maximum for ordinary outbox. Every run verified delivery of the expected MongoDB IDs and an empty Oracle outbox. Hot-account Busy stayed within the reference range. Raw performance values remain in private local evidence.

This change exposes the proven sequence in Oracle tuning tooling for disposable restored integration databases. Product queries, migrations, automatic statistics maintenance, generator behavior, normal benchmarks, CI settings, and performance criteria retain their existing behavior.
